**Project type:** Personal eCommerce Learning Project  
**Period:** August 2025  
**Repository:** [Supermarket-eCommerce-Website-Project](https://github.com/p-g-udara-dilshan/Supermarket-eCommerce-Website-Project)

---

> 🛒 **Project overview**  
> A personal WordPress eCommerce project created to explore the customer experience of an online supermarket, from browsing items to a checkout interface. Built with **WordPress** and **WooCommerce** as a practical learning project.

## ✨ Features Explored

- **Supermarket storefront:** homepage and product listing layouts.
- **Product catalogue:** individual product cards and product details.
- **Product discovery:** searching for products and browsing available items.
- **Ratings display:** product ratings as part of the storefront presentation.
- **Shopping cart:** add-to-cart and cart review workflows.
- **Checkout:** WooCommerce checkout interface.
- **Payment options configured:** bank transfer and cash on delivery.
- **Customer accounts:** registration and account-management interfaces.
- **Contact page:** a customer enquiry form.
- **Responsive presentation:** layouts for multiple screen sizes.

> **Payment clarification:** Showing bank transfer and cash-on-delivery options does not demonstrate automated payment settlement, order fulfilment, or successful real-world transaction processing.

## 🧭 Main Customer Journey

1. Explore the home page and browse products.
2. Find products using search or category navigation.
3. Inspect product details and available ratings.
4. Add items to the cart and review selections.
5. Continue to WooCommerce checkout and review the available payment methods.
6. Use customer account pages for account-related interactions.

## 👨‍💻 Learning & Development Focus

- Configuring an eCommerce site using WordPress and WooCommerce.
- Understanding how product catalogues, carts, customer accounts, and checkout pages connect.
- Improving storefront layout and mobile usability.
- Exploring common non-card checkout options within a prototype website.

## 🧰 Local Setup / Restoration

This is a **WordPress-based project**, not a standalone HTML/React application. The required installation steps depend on what files are actually present in this repository.

To recreate the original website **only if you have an authorized and complete site export**:

1. Prepare a local WordPress environment (such as Local, XAMPP, or an appropriate hosting account).
2. Install WordPress and provision a MySQL/MariaDB database.
3. Restore the original theme, child theme, plugins, media uploads, and database **if those backups are available**.
4. Review site URLs, WordPress permalinks, media references, navigation, and form configuration.
5. Reconfigure integrations and test the restored site on desktop and mobile.

**Important:** Screenshots, a theme folder, or a collection of page assets alone are **not** sufficient to restore a fully working WordPress installation. Do not publish database credentials, admin accounts, API keys, or private client information.
